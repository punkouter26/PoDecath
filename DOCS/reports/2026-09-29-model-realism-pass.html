Model realism pass

2026-09-29 · every model in Assets/Models checked against the 20-point game-ready list and the 5-step export pipeline

What changed in the game: six athlete files. Three of them (Grandma, Grandpa, Nick) were rendering as solid metal that also glowed with its own skin colour, which is why they looked flat and pasted-on. They now take light and shadow from the sun like cloth and skin, their faceted "low-poly" shading is smoothed, and they, plus Trump, have soft contact shadow in creases. Every original texture is kept byte-for-byte (house rule 16).

What did not change: the White House. It was already in good shape; the one fix that would have altered it (smoother edge shading) changed under 2 % of pixels in a close-up and made one corner look slightly flatter, so it was not worth replacing a 117 MB file and re-baking the lighting. The pass is saved for the next export from the .blend.

Proof nothing else moved

For every patched file the skeleton, the bind pose, every vertex position, the UVs, the triangle list and every original texture were compared byte-for-byte with the old file: all identical. The only data that differs is the material values, the new AO image, the smoothed normals on the four flat-shaded meshes, and Matt Avaturn's weights. Unity re-imported all six without an error and reports metal 0 / roughness 0.65 / AO on the three fixed athletes, and at most 4 bones per vertex on every mesh.

How to run it again

  • Check any model: blender-launcher --background --python training/tools/model_audit.py -- out.json <model.glb> …
  • Fix a new athlete glb: blender-launcher --background --python training/tools/athlete_glb_fix.py -- in.glb out.glb --ao
  • Building pass on the next export: blender-launcher --background --python training/tools/game_ready.py -- WhiteHouse.glb out.glb
  • Before/after stills: blender-launcher --background --python training/tools/render_preview.py -- model.glb prefix building|character [--ao]

Blender 5.2.2 is installed from the Microsoft Store; run it through blender-launcher, which does not pass Blender's printed output back, so each script also writes a log under training/logs/.
